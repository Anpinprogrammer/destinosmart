# Skill — frontend-ui (v4.0)

Aplicar a features UI. React + TypeScript strict, Tailwind CSS, Framer Motion; no introducir frameworks adicionales sin ADR. Especificar responsive/mobile-first, componentes, formularios, accesibilidad (teclado/contraste/lectores), internacionalización, skeletons, errores, estados vacíos y reducción de movimiento. Para landing, seis tarjetas con imágenes reales autorizadas y metadata de frescura. Definir contratos de props, tests de componentes y métricas de carga; aspiración a 60 fps se valida con mediciones, no mediante conjeturas.
