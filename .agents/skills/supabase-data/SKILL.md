# Skill — supabase-data (v4.0)

Aplicar al diseño de Auth, PostgreSQL, Storage, Realtime y Edge Functions Deno/TypeScript. Antes de implementar: esquema/migraciones, índices, relaciones, invariantes, aislamiento por usuario, permisos y políticas RLS testeadas (lectura y escritura). Nunca usar service_role en cliente ni llamar OpenRouter desde navegador. Validar JWT/claims en Edge Functions, schema de entradas y límites, concurrencia de cuotas y protección de race conditions. Decidir caché Database vs Redis mediante ADR; no asumir una opción implícita.
