# Skill — security-privacy

## Aplicación
Features con identidad, viajes guardados, IA, pagos, precios, notificaciones, proveedores o datos personales.

## Revisión mínima
- Amenazas, superficies de entrada/salida y controles de acceso.
- PII minimizada, retención y borrado, sin datos sensibles en logs.
- Secret manager/env, nunca tokens en cliente o repositorio.
- Rate limits, cuotas atómicas, antifraude y abuso de trial.
- Integraciones con least privilege y separación sandbox/producción.
- Operaciones de cobro/reserva: confirmación, idempotencia, reconciliación y tratamiento de errores.
- IA: protección de prompt injection, validación de output y aislamiento de contexto entre usuarios.

## Salida
Riesgos por severidad, controles previstos, pruebas y aceptación humana cuando proceda.
